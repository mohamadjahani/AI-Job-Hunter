# AI Job Hunter — Privacy Policy

**Last updated:** November 12, 2026

## 1. Overview

AI Job Hunter is a personal, Python-based job search and resume-tailoring application developed by Mohammadhossein Jahani.

The application uses Gmail integration, automated job processing, and AI-assisted analysis to help identify relevant employment opportunities.

## 2. Information Accessed

With the user's authorization, AI Job Hunter may access:

- Gmail messages containing job alerts and employment opportunities.
- Job titles, company names, locations, descriptions, and application links.
- Resume information voluntarily provided by the user.

Gmail access uses the `gmail.readonly` permission. The application does not require permission to send, modify, or delete Gmail messages.

## 3. How Information Is Used

Information is used to:

- Identify and extract relevant job opportunities.
- Analyze job descriptions and compare requirements with the user's qualifications.
- Generate job-specific resume drafts for manual review.

AI-powered features may transmit relevant job descriptions and resume information to the configured AI service provider for processing.

## 4. Data Storage and Security

The application is designed for local execution.

OAuth credentials and tokens, private resumes, and generated documents are stored locally and excluded from the public Git repository through Git ignore rules.

The application does not intentionally sell personal information or share Gmail data for advertising purposes.

## 5. Google User Data

Google user data is accessed only with user authorization and used to support the application's job discovery functionality.

The application's use of Google user data is intended to comply with the Google API Services User Data Policy, including the Limited Use requirements.

## 6. Data Retention and Deletion

Locally stored OAuth tokens, resumes, and generated job documents can be deleted by the user.

Users can revoke the application's Google account access through their Google Account security settings.

## 7. Changes to This Policy

This policy may be updated as the application evolves. Changes will be published in this repository.
